# Tractor Repair Marketplace — Database Documentation

## Architecture & Technology
- **Engine**: PostgreSQL 15+ with `postgis`, `pgcrypto`, and `uuid-ossp` extensions.
- **Provider**: Supabase managed database with Row Level Security (RLS) on all 29 tables.
- **Spatial Indexing**: PostGIS `geography(Point, 4326)` for mechanic real-time locations and customer tractor repair pins.
- **Monetary Precision**: `numeric(12, 2)` for currency calculations to prevent floating point inaccuracies.

## Tables & Schemas

### 1. `profiles`
Central user registry linked 1:1 with `auth.users`.
- `id` (UUID PK, references `auth.users`)
- `role` (`user_role`: `'customer'`, `'mechanic'`, `'admin'`)
- `full_name` (text)
- `phone` (text)
- `avatar_url` (text nullable)
- `preferred_language` (text default `'en'`)
- `is_active` (boolean default `true`)
- `created_at`, `updated_at` (timestamptz)

### 2. `customers`
- `id` (UUID PK)
- `profile_id` (UUID FK `profiles`)
- `default_tractor_id` (UUID FK `tractors` nullable)
- `created_at`, `updated_at`

### 3. `tractors`
- `id` (UUID PK)
- `customer_id` (UUID FK `customers`)
- `make` (text) — e.g. Mahindra, Swaraj, John Deere, Sonalika, Massey Ferguson, New Holland
- `model` (text) — e.g. 575 DI, 744 FE, 5050 D
- `year` (int nullable)
- `registration_number` (text nullable)
- `created_at`, `updated_at`

### 4. `mechanics`
- `id` (UUID PK)
- `profile_id` (UUID FK `profiles`)
- `status` (`mechanic_status`: `'pending'`, `'approved'`, `'rejected'`, `'suspended'`)
- `experience_years` (int)
- `workshop_address` (text)
- `service_radius_km` (numeric default `25.0`)
- `is_online` (boolean default `false`)
- `current_location` (`geography(Point, 4326)`)
- `rating_avg` (`numeric(3, 2)` default `0.00`)
- `total_jobs` (int default `0`)
- `admin_notes` (text nullable)
- `approved_at` (timestamptz nullable)
- `approved_by` (UUID FK `profiles` nullable)
- `created_at`, `updated_at`

### 5. `problem_categories`
- `id` (UUID PK)
- `name_en` (text) — e.g. Engine
- `name_te` (text) — e.g. ఇంజన్
- `name_hi` (text) — e.g. इंजन
- `icon` (text)
- `sort_order` (int)
- `is_active` (boolean)

### 6. `mechanic_skills`
Composite Primary Key: `(mechanic_id, category_id)`

### 7. `mechanic_documents`
Protected identification files (Aadhaar, PAN, Workshop License).
- Stored in private Supabase Storage bucket `mechanic-documents`.
- Read access requires short-lived signed URLs generated by administrator edge functions.

### 8. `repair_requests`
- `id` (UUID PK)
- `customer_id` (UUID FK `customers`)
- `tractor_id` (UUID FK `tractors`)
- `category_id` (UUID FK `problem_categories`)
- `description` (text nullable)
- `voice_note_url` (text nullable)
- `latitude` (`numeric(10, 7)`)
- `longitude` (`numeric(10, 7)`)
- `location` (`geography(Point, 4326)` generated via trigger)
- `address_text` (text nullable)
- `status` (`job_status`)

### 9. `secure_codes`
Expiring, single-use, hashed validation codes.
- `id` (UUID PK)
- `job_id` (UUID FK `jobs`)
- `code_type` (`'start'` | `'finish'`)
- `code_hash` (text NOT NULL)
- `expires_at` (timestamptz)
- `max_attempts` (int default 3)
- `attempts` (int default 0)
- `is_used` (boolean default false)
- `used_at` (timestamptz nullable)
- `verified_by` (UUID FK `profiles` nullable)

## Geospatial Proximity Matching Query

Matching algorithm executed by `match-mechanic` Edge Function:

```sql
SELECT 
    m.id AS mechanic_id,
    p.full_name,
    p.phone,
    m.rating_avg,
    m.workshop_address,
    ST_Distance(m.current_location, req.location) / 1000.0 AS distance_km
FROM mechanics m
JOIN profiles p ON p.id = m.profile_id
JOIN mechanic_skills ms ON ms.mechanic_id = m.id
CROSS JOIN (
    SELECT location, category_id 
    FROM repair_requests 
    WHERE id = :requestId
) req
WHERE m.status = 'approved'
  AND m.is_online = true
  AND ms.category_id = req.category_id
  AND ST_DWithin(m.current_location, req.location, m.service_radius_km * 1000.0)
ORDER BY distance_km ASC
LIMIT 5;
```

## Row Level Security (RLS) Enforcement

RLS is strictly active on all 29 tables:
- **Customers**: Can query and update only their own profile, tractors, and requests.
- **Mechanics**: Can read assigned requests, their own earnings, documents, and submit quotes.
- **Administrators**: Governed by `is_admin(auth.uid())` which executes with `SECURITY DEFINER` against user roles.
- **Public**: Only active problem categories and public reviews are publicly readable.
